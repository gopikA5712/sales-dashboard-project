# 📊 Sales Data Dashboard

This project analyzes sales data to generate business insights using Python and Plotly.

## 🔧 Tools Used
- Python
- Pandas
- Plotly

## 📈 Features
- KPI Metrics
- Sales Trend Analysis
- Region-wise Sales
- Category Insights

## 🚀 Insights
- Identified top-performing regions and products
- Visualized sales trends over time
